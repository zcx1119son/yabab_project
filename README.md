# **🏟️ YABAB (Yet Another Baseball App Builder): 전국 야구장 먹거리 공유 및 커뮤니티 플랫폼**

## **💡 프로젝트 개요 (Project Overview)**

YABAB은 야구장 방문객들이 경기장 주변 및 내부의 먹거리 정보(맛집, 메뉴, 가격 등)를 공유하고 소통하는 **풀스택 웹 플랫폼**입니다. 본 시스템은 일반 사용자, 사장님, 관리자라는 세 가지 권한 레벨을 가지며, 각 역할에 맞는 전용 페이지와 기능을 제공합니다.

* **프로젝트 기간:** 2025.06.26 \~ 2025.07.26  
* **핵심 목표:** 야구장 먹거리 정보의 접근성 향상 및 사용자 간 정보 공유 활성화

## **⚙️ 개발 환경 및 기술 스택 (Tech Stack)**

| 구분 | 기술 / 라이브러리 | 상세 내용 |
| :---- | :---- | :---- |
| **Backend** | Spring Boot 3.x, Spring Security | RESTful API 설계 및 **JWT 기반 인가 처리** |
| **Database** | Oracle, JPA | 관계형 데이터베이스 설계 및 데이터 관리 |
| **Frontend** | React, TypeScript, Tailwind CSS | 컴포넌트 기반 UI 구현 및 반응형 웹 디자인 |
| **인증/결제** | **카카오 로그인 (OAuth)** | 소셜 로그인 연동을 통한 사용자 편의성 증대 |
